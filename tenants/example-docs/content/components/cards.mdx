# Cards

Cards are the linkable container blocks. They support a title, optional icon, optional image, and an `href` to make the whole card clickable.

## Single Card

<Card title="Quick Start" icon="rocket" href="/getting-started/installation">

</Card>

## CardGroup

`CardGroup` arranges multiple cards into a responsive grid. The `cols` prop controls the layout.

<CardGroup cols={2}>
  <Card title="Components" icon="layers" href="/components/tabs">
    Browse every block this tenant exercises.
  </Card>
  <Card title="API Reference" icon="code" href="/api/users">
    Document REST endpoints with structured fields.
  </Card>
  <Card title="Installation" icon="download" href="/getting-started/installation">
    Step-by-step setup for new contributors.
  </Card>
  <Card title="Home" icon="home" href="/">
    Back to the landing page.
  </Card>
</CardGroup>

## Frame

`Frame` wraps an image (or arbitrary content) with a caption and a subtle border. Useful for screenshots and diagrams.

<Frame caption="An example screenshot frame.">
  <img src="/assets/example.png" alt="Example screenshot" />
</Frame>

<Callout type="tip">
  Frame's child can be any block. The most common case is `<img>`, but you can also wrap a `<video>` or a Mermaid diagram.
</Callout>
