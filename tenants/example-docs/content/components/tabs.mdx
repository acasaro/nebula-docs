# Tabs

Tabs are switchable content panels. Useful for showing the same instruction in multiple languages, or grouping related views.

## Basic usage

<Tabs>
  <Tab title="JavaScript">
    ```js
    function greet(name) {
      return `Hello, ${name}!`;
    }
    ```
  </Tab>
  <Tab title="TypeScript">
    ```ts
    function greet(name: string): string {
      return `Hello, ${name}!`;
    }
    ```
  </Tab>
  <Tab title="Python">
    ```python
    def greet(name: str) -> str:
        return f"Hello, {name}!"
    ```
  </Tab>
</Tabs>

## With richer content

A Tab's children can be any block, not just code. Mix prose, callouts, and components freely.

<Tabs>
  <Tab title="Overview">
    Tabs sync by title across the page when multiple `Tabs` containers share the same titles. Pick "JavaScript" in one container and the same title is auto-selected in any other container on the same page.
  </Tab>
  <Tab title="Customization">
    <Callout type="info">
      The default tab is the first one. Use the `active` attribute on a `Tab` to override.
    </Callout>
  </Tab>
</Tabs>
