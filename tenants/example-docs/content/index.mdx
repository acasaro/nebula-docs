# Welcome to Example Docs

This is a synthetic tenant repository. It exists to let the Nebula Docs CLI render every block in `@nebula-docs/components` against a real tenant shape, without round-tripping through GitHub.

<Callout type="info">
  Real tenants live in their own GitHub repos. This one lives inside the monorepo as a development fixture.
</Callout>

## What's here

- **Getting Started** — installation walkthrough using `Steps`, `Callout`, code blocks, and a `Snippet` include.
- **Components** — `Card` / `CardGroup` / `Frame` and `Tabs` / `Tab` examples.
- **API Reference** — `ParamField` / `ResponseField` / `RequestExample` / `ResponseExample` for the Users endpoint.

Pick any of the above from the sidebar to see the corresponding components rendered.
