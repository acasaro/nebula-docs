## Prerequisites

- Node.js 22 or later
- pnpm 10 or later
- A Nebula Docs CLI install (`@nebula-docs/cli`)

## Steps

<Steps>
  <Step title="Clone the repository">
    Pull the tenant repo from GitHub.

    ```bash
    git clone git@github.com:your-org/your-docs.git
    cd your-docs
    ```
  </Step>
  <Step title="Install dependencies">
    Run pnpm install in the project root.

    ```bash
    pnpm install
    ```

    <Callout type="info">
      The install pulls `@nebula-docs/cli` and any tenant-specific React components in `components/`.
    </Callout>
  </Step>
  <Step title="Start the dev server">
    The CLI's dev server gives you HMR-backed local rendering.

    ```bash
    pnpm nebula dev
    ```

    Open [http://localhost:4321](http://localhost:4321) in your browser.
  </Step>
  <Step title="Build for production">
    When you're ready to ship, run the build.

    ```bash
    pnpm nebula build
    ```

    The static output lands in `dist/`. Your CI workflow uploads that directory to your OOSS bucket.
  </Step>
</Steps>
