The AcmeCloud REST API is hosted at `https://api.acmecloud.example/v2`. Every request must include an API key — see [Quickstart](/quickstart) to mint one.

<Callout type="info" title="Authentication required">
  All AcmeCloud API requests must include an `Authorization: Bearer <token>` header.
</Callout>

## Conventions

- **Base URL** — `https://api.acmecloud.example/v2`
- **Auth** — `Authorization: Bearer <token>`
- **Content type** — `application/json` on requests and responses
- **Errors** — non-2xx responses always include a JSON body with `error.code` and `error.message`
- **Versioning** — the major version is in the URL; minor and patch versions are header-accepted but optional
- **Idempotency** — write endpoints accept an `Idempotency-Key` header for safe retries

<Callout type="note" title="Rate limits">
  Free-tier projects are limited to **120 requests/minute** per API key. Paid tiers raise the ceiling to 10,000 rpm. Every response includes `X-RateLimit-Remaining` and `X-RateLimit-Reset` headers so SDK clients can back off cleanly.
</Callout>

## Error format

All non-2xx responses share this body shape:

```json
{
  "error": {
    "code": "invalid_token",
    "message": "The provided API key has been revoked.",
    "requestId": "req_8f2c9a..."
  }
}
```

<Property name="error.code" type="string">
  Machine-readable error class. SDKs map these to typed error subclasses.
</Property>

<Property name="error.message" type="string">
  Human-readable description. Safe to surface to end users.
</Property>

<Property name="error.requestId" type="string">
  Unique request identifier. Include this when filing a support ticket.
</Property>

## Common error codes

| Status | Code | Meaning |
|---|---|---|
| 400 | `invalid_request` | The request body or query failed schema validation |
| 401 | `invalid_token` | The API key is missing, malformed, or revoked |
| 403 | `forbidden` | The token is valid but lacks the scope for this endpoint |
| 404 | `not_found` | The resource does not exist or is not visible to this token |
| 409 | `conflict` | A unique constraint was violated (e.g., duplicate user email) |
| 429 | `rate_limited` | Per-key or per-project rate limit exceeded |
| 500 | `internal_error` | Server-side failure. Includes a `requestId` for support |
| 503 | `service_unavailable` | A region is failing over. Retry with backoff |
