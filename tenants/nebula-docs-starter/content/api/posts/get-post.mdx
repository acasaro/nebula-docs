Retrieve a single post. Posts are versioned; the latest revision is returned unless you pin one explicitly.

```
GET https://api.acmecloud.example/v2/posts/:id
```

## Path parameters

<ParamField path="id" type="string" required>
  The post's stable global identifier. Format: `pst_<24 hex>`.
</ParamField>

## Query parameters

<ParamField query="revision" type="number">
  Pin to a specific revision number. Omit to get the latest.
</ParamField>

<ParamField query="include" type="string">
  Comma-separated list of related resources to embed. Supported: `author`, `comments`.
</ParamField>

## Response — 200 OK

<ResponseField name="id" type="string">
  Stable global identifier.
</ResponseField>

<ResponseField name="authorId" type="string">
  Foreign key to `user.id`.
</ResponseField>

<ResponseField name="title" type="string">
  Free-form title.
</ResponseField>

<ResponseField name="body" type="string">
  Markdown body. Up to 256 KB.
</ResponseField>

<ResponseField name="tags" type="string[]">
  Free-form tags.
</ResponseField>

<ResponseField name="revision" type="number">
  Monotonically increasing version number.
</ResponseField>

<ResponseField name="createdAt" type="string">
  ISO-8601 timestamp.
</ResponseField>

<ResponseField name="updatedAt" type="string">
  ISO-8601 timestamp of the most recent update (matches the revision's create time).
</ResponseField>

<ResponseField name="author" type="object">
  Embedded only when `include=author` is set. Same shape as [`GET /users/:id`](/api/users/get-user).
</ResponseField>

## Examples

<RequestExample>
  ```bash cURL
  curl 'https://api.acmecloud.example/v2/posts/pst_4f8c?include=author' \
    -H "Authorization: Bearer $ACME_KEY"
  ```

  ```ts TypeScript
  const post = await client.posts.get('pst_4f8c', {
    include: 'author',
  });
  ```
</RequestExample>

<ResponseExample>
  ```json 200
  {
    "id": "pst_4f8c",
    "authorId": "usr_e8a3",
    "title": "Welcome to AcmeCloud",
    "body": "# Hello world\n\nThis is the seed post...",
    "tags": ["announcement", "welcome"],
    "revision": 3,
    "createdAt": "2026-01-20T10:00:00Z",
    "updatedAt": "2026-04-30T15:42:11Z"
  }
  ```
</ResponseExample>

<Callout type="info">
  Pin a revision when you need stable content for analytics or a snapshot view. Otherwise let the latest float.
</Callout>
