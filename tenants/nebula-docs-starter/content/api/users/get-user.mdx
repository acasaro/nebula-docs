Retrieve a single user record by their stable identifier.

```
GET https://api.acmecloud.example/v2/users/:id
```

## Path parameters

<ParamField path="id" type="string" required>
  The user's unique identifier. Format: `usr_<24 hex>`.
</ParamField>

## Query parameters

<ParamField query="include" type="string">
  Comma-separated list of related resources to embed in the response. Supported values: `posts`, `roles`, `organization`.
</ParamField>

<ParamField query="fields" type="string">
  Comma-separated subset of fields to return. Useful for trimming payloads on mobile clients.
</ParamField>

## Response — 200 OK

<ResponseField name="id" type="string">
  Stable identifier scoped to the project.
</ResponseField>

<ResponseField name="email" type="string">
  Unique within the project.
</ResponseField>

<ResponseField name="name" type="string">
  Optional display name.
</ResponseField>

<ResponseField name="roles" type="string[]">
  Role identifiers granted to the user.
</ResponseField>

<ResponseField name="profile" type="object">
  Optional profile metadata.

  <Expandable title="properties">
    <ResponseField name="profile.avatarUrl" type="string">
      Public URL to the user's avatar.
    </ResponseField>
    <ResponseField name="profile.bio" type="string">
      Short biography.
    </ResponseField>
    <ResponseField name="profile.timezone" type="string">
      IANA timezone identifier.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="createdAt" type="string">
  ISO-8601 timestamp of when the user was created.
</ResponseField>

<ResponseField name="updatedAt" type="string">
  ISO-8601 timestamp of the most recent update.
</ResponseField>

## Examples

<RequestExample>
  ```bash cURL
  curl https://api.acmecloud.example/v2/users/usr_e8a3 \
    -H "Authorization: Bearer $ACME_KEY"
  ```

  ```ts TypeScript
  const user = await client.users.get('usr_e8a3', {
    include: 'posts,roles',
  });
  ```

  ```python Python
  user = client.users.get('usr_e8a3', include=['posts', 'roles'])
  ```
</RequestExample>

<ResponseExample>
  ```json 200
  {
    "id": "usr_e8a3",
    "email": "ada@example.com",
    "name": "Ada Lovelace",
    "roles": ["editor", "reviewer"],
    "profile": {
      "avatarUrl": "https://cdn.acmecloud.example/avatars/usr_e8a3.png",
      "bio": "Software engineer.",
      "timezone": "Europe/London"
    },
    "createdAt": "2026-01-15T08:30:00Z",
    "updatedAt": "2026-04-02T17:14:22Z"
  }
  ```

  ```json 404
  {
    "error": {
      "code": "not_found",
      "message": "No user with id usr_e8a3.",
      "requestId": "req_8f2c9a"
    }
  }
  ```
</ResponseExample>

<Callout type="tip">
  Pass `include=posts` to embed up to the user's most-recent 10 posts. For full pagination over their post history, use `GET /posts?authorId=...` instead.
</Callout>
