List users in the project. Cursor-based pagination — no offset.

```
GET https://api.acmecloud.example/v2/users
```

## Query parameters

<ParamField query="limit" type="number" default="20">
  Page size. 1–100.
</ParamField>

<ParamField query="cursor" type="string">
  Opaque cursor from a previous response's `pagination.next`. Omit to start at the first page.
</ParamField>

<ParamField query="role" type="string">
  Filter by role. Multi-valued — pass `?role=editor&role=admin` to OR them.
</ParamField>

<ParamField query="search" type="string">
  Free-text search over email and name. Case-insensitive substring match.
</ParamField>

<ParamField query="sort" type="'createdAt' | 'updatedAt' | 'email'" default="createdAt">
  Sort field. Always descending.
</ParamField>

## Response — 200 OK

<ResponseField name="users" type="User[]">
  Array of user records. Same shape as [`GET /users/:id`](/api/users/get-user).
</ResponseField>

<ResponseField name="pagination" type="object">
  Cursor pagination metadata.

  <Expandable title="properties">
    <ResponseField name="pagination.next" type="string">
      Opaque cursor for the next page. `null` when on the last page.
    </ResponseField>
    <ResponseField name="pagination.prev" type="string">
      Opaque cursor for the previous page.
    </ResponseField>
    <ResponseField name="pagination.hasMore" type="boolean">
      Convenience flag mirroring `pagination.next !== null`.
    </ResponseField>
  </Expandable>
</ResponseField>

## Examples

<RequestExample>
  ```bash cURL
  curl 'https://api.acmecloud.example/v2/users?limit=50&role=editor' \
    -H "Authorization: Bearer $ACME_KEY"
  ```

  ```ts TypeScript
  const page = await client.users.list({
    limit: 50,
    role: ['editor'],
  });

  let cursor = page.pagination.next;
  while (cursor) {
    const next = await client.users.list({ cursor });
    // ... process page
    cursor = next.pagination.next;
  }
  ```

  ```python Python
  for user in client.users.list_all(role=['editor']):
      print(user.email)
  ```
</RequestExample>

<Callout type="info">
  The TypeScript SDK exposes `client.users.listAll()` as an async iterator that handles cursor walking for you. Prefer it over the raw `list()` for full-corpus walks.
</Callout>
