title: Callout
description: Admonition blocks for asides, warnings, tips, and danger notices.
---
`<Callout>` is the all-purpose admonition. Pick a `type` to control the icon and color. The aliases `<Info>`, `<Note>`, `<Tip>`, `<Check>`, `<Warning>`, and `<Danger>` are equivalent to passing the corresponding `type`.

## All variants

<Info>
**Info** — neutral context. Background information that helps but isn't critical.
</Info>

<Note>
**Note** — something the reader should be aware of, but not act on immediately.
</Note>

<Tip>
**Tip** — a non-obvious recommendation or shortcut.
</Tip>

<Check>
**Check** — confirmation that something is set up correctly.
</Check>

<Warning>
**Warning** — describes a footgun. Reading this avoids the foot.
</Warning>

<Danger>
**Danger** — describes irreversible damage. Stop and read carefully.
</Danger>

## With a custom title

Rotating mid-deploy can leave one runner using the old key and one using the new. Use the 24-hour grace window — don't revoke until every workflow has redeployed.
</Warning>

## Aliases

The shorter alias forms work the same:

<Note>This is `<Note>` — same as `<Callout type="note">`.</Note>

<Tip>This is `<Tip>`.</Tip>

<Warning>This is `<Warning>`.</Warning>
