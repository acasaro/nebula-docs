In MDX, you usually write code as a fenced block — \`\`\`lang...\`\`\` — and the renderer converts it to a `<CodeBlock>` automatically. The component accepts the same `language` and optional `filename` you'd pass through fence info.

## Plain fenced block

```ts
function add(a: number, b: number): number {
  return a + b;
}
```

## With a filename

The first non-`key=value` token after the language is treated as a filename and shown above the code:

```ts add.ts
function add(a: number, b: number): number {
  return a + b;
}
```

## Many languages

```python
def add(a: int, b: int) -> int:
    return a + b
```

```go
func Add(a, b int) int {
    return a + b
}
```

```rust
fn add(a: i32, b: i32) -> i32 {
    a + b
}
```

```bash
echo "$((1 + 2))"
```

```sql
SELECT a + b AS sum FROM operands;
```

```yaml
operands:
  - a: 1
  - b: 2
```

```json
{ "a": 1, "b": 2 }
```

```diff
-function add(a, b) { return a - b; }
+function add(a, b) { return a + b; }
```

## A longer sample

```ts users.ts lines
import { AcmeCloud } from "@acmecloud/sdk";

export async function listEditors(client: AcmeCloud) {
  const all = await client.users.list({ limit: 100 });
  return all.users.filter((u) => u.roles.includes("editor"));
}
```

<Callout type='tip'>
  Filenames render as a small chip above the code. Use them on tutorial pages where the reader needs
  to know which file the snippet goes into.
</Callout>
