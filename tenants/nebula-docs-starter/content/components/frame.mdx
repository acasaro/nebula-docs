description: 'Bordered surround for screenshots, with an optional caption.'
icon: 'image'
---

`<Frame>` wraps a child block (usually an image) in a rounded surround with a subtle dot grid. Use it for screenshots, diagrams, or anything else that benefits from chrome separating it from surrounding prose.

</Frame>

  <Mermaid>
    {`flowchart LR
      A[Client SDK] --> B[Edge node]
      B --> C[Region]
      C --> D[(Storage)]`}
  </Mermaid>
</Frame>
