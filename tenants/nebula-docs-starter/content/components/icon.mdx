---
title: Icon
description: Render an icon by name from the Lucide / Material / Material Symbols corpora.
---
`<Icon>` resolves an icon name + library + variant to a CDN URL and renders the SVG via `mask-image` so the icon recolors via `currentColor`.

## Default (Lucide)

The default library is `lucide`. No `iconLibrary` prop needed.

<Icon icon="rocket" />

<Icon icon="users" />

<Icon icon="folder" />

<Icon icon="settings" />

<Icon icon="search" />

## Recolored via `currentColor`

By default, an icon takes `color: currentColor`, so it inherits the surrounding text color:

<span style={{ color: '#16a34a' }}>
  <Icon icon="check-circle" /> Operational
</span>

{' '}

<span style={{ color: '#dc2626' }}>
  <Icon icon="x-circle" /> Incident
</span>

## Inline with text

Click the <Icon icon="settings" size={14} /> icon in the navbar to open Settings.

<Tip>
Icons used in component props (`<Card icon="rocket">`) accept the same name; the parent component wires up size + color appropriately.
</Tip>
