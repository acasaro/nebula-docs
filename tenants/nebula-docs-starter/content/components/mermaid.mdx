`<Mermaid>` renders a [Mermaid](https://mermaid.js.org) diagram client-side. The library lazy-loads on first render so pages without diagrams pay zero JS cost.

## Flowchart

<Mermaid>
{`flowchart LR
  A[Client SDK] --> B[Edge node]
  B -->|cache hit| A
  B -->|miss| C[Region]
  C --> D[(Storage)]
  C --> A`}
</Mermaid>

## Sequence diagram

<Mermaid>
{`sequenceDiagram
  participant SDK
  participant Edge
  participant Region
  participant Storage
  SDK->>Edge: POST /users
  Edge->>Edge: validate token
  Edge->>Region: forward
  Region->>Storage: write
  Storage-->>Region: ack
  Region-->>Edge: 201 Created
  Edge-->>SDK: 201 Created`}
</Mermaid>
