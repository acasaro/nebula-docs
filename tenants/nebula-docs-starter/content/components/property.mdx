---
title: Property
description: The primitive behind ParamField and ResponseField.
---
`<Property>` is the field-row primitive used in API references. It renders a name + type + pills row, then a description body. `<ParamField>` and `<ResponseField>` are aliases that normalize Mintlify's `path` vs `name` conventions onto the same primitive.

## Plain property

<Property name="user.email" type="string">
  The user's email address.
</Property>

## Required + with a default

<Property name="user.roles" type="string[]" required default="['member']">
  Role identifiers granted to the user. Defaults to a single `member` role.
</Property>

## Deprecated

<Property name="user.legacyId" type="string" deprecated>
  Pre-v2 numeric ID. Read-only; new users do not have one.
</Property>

## With pre / post pills

<Property name="endpoint" type="string" pre={['Required']} post={['Cached 30s']}>
  The fully qualified API base URL.
</Property>

## With a location

<Property name="X-Project-Id" type="string" location="header">
  Override the default project resolution by setting this header.
</Property>

## ParamField alias

`<ParamField>` is the same primitive but exposes `path` for the Mintlify-shaped MDX:

<ParamField path="id" type="string" required>
The user's unique identifier.
</ParamField>

<ParamField query="include" type="string">
Comma-separated list of related resources to include.
</ParamField>

## ResponseField alias

<ResponseField name="id" type="string">
The user's unique identifier.
</ResponseField>

<ResponseField name="email" type="string">
The user's email address.
</ResponseField>

<ResponseField name="roles" type="string[]">
Array of role identifiers granted to the user.
</ResponseField>
