## With rich body content

<Update label="v2.0.0" description="2025-10-01" tags={['breaking', 'platform']}>
### Breaking changes

- `Authorization` header now requires the `Bearer ` prefix
- `users.list()` pagination shape changed from offset to cursor

### Migration

Run `pnpm exec acmecloud migrate v1-v2` to update both your `.env` files and any in-tree fixtures. The migration is idempotent — re-running it is safe.

<Warning>
Pre-2.0 clients sending raw keys without the `Bearer` prefix get a 401 with a migration hint in the response body.
</Warning>
</Update>
