AcmeCloud is a fictional placeholder product used to populate this kitchen-sink Nebula Docs starter. The SDK lets you provision *projects*, manage *users*, publish *posts*, and stream telemetry from any runtime that can speak HTTPS.

The AcmeCloud SDK is published for three runtimes. Examples on this page assume the latest minor version of each:

- **TypeScript** — `@acmecloud/sdk` v2.4.x (Node 20+)
- **Python** — `acmecloud-sdk` 2.4.x (Python 3.11+)
- **Go** — `github.com/acmecloud/sdk-go` v2.4.x (Go 1.22+)

## A 30-second taste

<CodeGroup>
```ts
import { AcmeCloud } from '@acmecloud/sdk';
  const client = new AcmeCloud({ apiKey: process.env.ACME_KEY });
  const user = await client.users.create({
    email: 'ada@example.com',
    name: 'Ada Lovelace',
  });
```

```python
from acmecloud import AcmeCloud

  client = AcmeCloud(api_key=os.environ['ACME_KEY'])

  user = client.users.create(
      email='ada@example.com',
      name='Ada Lovelace',
  )
```

```go
client := acmecloud.New(os.Getenv("ACME_KEY"))

  user, err := client.Users.Create(ctx, &acmecloud.UserCreate{
      Email: "ada@example.com",
      Name:  "Ada Lovelace",
  })
```
</CodeGroup>
