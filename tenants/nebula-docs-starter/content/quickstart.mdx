<Info>
All AcmeCloud API requests must include an `Authorization: Bearer <token>` header. Mint a key in the steps below.
</Info>

## Prerequisites

<Prereqs />

You'll need:

- An AcmeCloud account (sign up at the fictional `console.acmecloud.example`)
- One of the supported runtimes from the [SDK matrix](#sdk-matrix)
- Five minutes

## SDK matrix

The AcmeCloud SDK ships for three runtimes:

- **TypeScript** — `@acmecloud/sdk` v2.4.x (Node 20+)
- **Python** — `acmecloud-sdk` 2.4.x (Python 3.11+)
- **Go** — `github.com/acmecloud/sdk-go` v2.4.x (Go 1.22+)

## Mint an API key

<Steps>
<Step title="Open the dashboard">
Sign in to the AcmeCloud console and pick a project from the switcher.
</Step>

<Step title="Generate a key">
From **Settings → API keys**, click **Create key**. Scope it to `read:users` and `write:users` for this walkthrough.

<Warning>
Keys are shown once. Copy it into your password manager before leaving the page.
</Warning>
</Step>

<Step title="Export it locally">
```bash
export ACME_KEY="acme_live_..."
```
</Step>
</Steps>

## Send your first request

<Tabs>
<Tab title="TypeScript">
```ts
import { AcmeCloud } from '@acmecloud/sdk';

const client = new AcmeCloud({ apiKey: process.env.ACME_KEY });

const me = await client.users.me();
console.log(`Hello, ${me.name}`);
```
</Tab>

<Tab title="Python">
```python
from acmecloud import AcmeCloud

client = AcmeCloud(api_key=os.environ['ACME_KEY'])
me = client.users.me()
print(f'Hello, {me.name}')
```
</Tab>

<Tab title="Go">
```go
client := acmecloud.New(os.Getenv("ACME_KEY"))
me, err := client.Users.Me(ctx)
if err != nil {
    log.Fatal(err)
}
fmt.Printf("Hello, %s\n", me.Name)
```
</Tab>

<Tab title="cURL">
```bash
curl https://api.acmecloud.example/v2/users/me \
  -H "Authorization: Bearer $ACME_KEY"
```
</Tab>
</Tabs>
