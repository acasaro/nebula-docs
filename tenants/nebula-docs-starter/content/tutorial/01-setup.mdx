This is part one of a two-part tutorial. By the end of this page you'll have a TypeScript app talking to an AcmeCloud project. Part two — [Deploy](/tutorial/02-deploy) — takes the same app to production.

<Info>
All AcmeCloud API requests must include an `Authorization: Bearer <token>` header. Mint a key in the steps below.
</Info>

## Scaffold the project

```bash
npx create-acme-app@latest acme-todo
cd acme-todo
```

The scaffold drops a Vite + React + TypeScript shell with the SDK pre-installed and an example screen wired to `client.users.me()`.

## Connect a project

<Steps>
<Step title="Create a project">
From the AcmeCloud console, click **New project**. Name it `acme-todo-dev`. Pick the `us-east` home region.
</Step>

<Step title="Generate a key">
From **Settings → API keys**, mint a key scoped to `read:users`, `write:users`, `read:posts`, `write:posts`.
</Step>

<Step title="Add it to .env">
```bash
echo 'ACME_KEY=acme_live_...' >> .env.local
```
</Step>
</Steps>

## Verify the connection

```bash
npm run dev
```

Open http://localhost:5173. You should see "Hello, &lt;your name&gt;" in the header — that's the SDK's `users.me()` call resolving against your project.
